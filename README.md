# Miami Plan (static clone)

Static HTML/CSS/vanilla JS clone of https://miami-plan-gta.vercel.app/

## Serve locally

```bash
cd miami-plan
python3 -m http.server 8765
```

Open http://127.0.0.1:8765/

## Stack

- Plain HTML + CSS + vanilla JS
- [Swiper 11](https://swiperjs.com/) (vendored under `vendor/swiper/`) for plan-card and buy-bar carousels
- Media/fonts downloaded from the reference site into `assets/`
